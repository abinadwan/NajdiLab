## Known limitation introduced by retaining PR #21's preset gate

Presets unlock only with a GPU memory estimate. On a machine where `nvidia-smi` is unavailable (CPU-only, or NajdiLab Native on CPU), presets stay locked with "Memory estimate unavailable"; the same values can be entered as Custom. This is PR #21's deliberate behavior and is kept; changing it needs an owner decision.
