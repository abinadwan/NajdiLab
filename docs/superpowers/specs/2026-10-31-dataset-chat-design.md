# Dataset-first NajdiLab design

Authority: current owner execution request; [read-only audit](../../scope-audit-2026-10-31.md). Implement directly in this isolated branch under that authorization; only destructive/ambiguous data choices require another decision.

Alternatives: a rewrite duplicates proven review/export gates and risks data. Removing all legacy modules/migrations breaks history and imports. Selected approach: extend the existing transactional service, add a small session coordinator and engine boundary, retire execution at HTTP/CLI boundaries, retain history and applied migrations.

Chat sessions own fixed provider/model, a user budget and reply reservation. Saved history contains only complete raw pairs. No NajdiLab system/developer messages, tools, retrieval, rewriting, hidden summarization, dropped messages or external memory. The engine applies its normal template. Never auto-load a model. LM Studio uses an optional pinned SDK for a loaded handle, template/tokenizer, loaded ceiling and prediction with stop-at-limit. Unsupported/ambiguous capability blocks before inference. Ollama exact preflight remains a documented blocker; do not invent precision.

One session has one active turn; request UUID and expected revision protect retries and stale tabs. Collection is a separate explicit per-session toggle, OFF on creation/restart. Revocation and stop take effect before commit. Disconnect waits for active engine access and cannot allow a later capture. A completed pair, optional pending review and idempotency receipt commit atomically using the existing ingest transaction. Failure, interruption, invalid result or stop commits no pair. Context overflow closes/preserves the current session and returns a new empty session, without replaying the rejected draft. Provider/model change requires a new session. Archiving cancels active work and excludes associated reviews from training; it does not erase data or frozen exports.

Hardware uses an explicit bounded read-only request, returns available RAM/GPU memory or unknown, and explains unavailable KV/overhead/placement. No numeric memory-safe recommendation without complete evidence. No automatic stress testing.

Remove training/navigation controls from current UI and refuse all training namespace writes with structured 410 before body parsing. Existing read-only job/attempt/log/metric access remains; no training initialization at startup. Dataset creation, validation, manual edits, review, versions and export contracts remain intact. Add a versioned Unsloth handoff derived only from eligible text conversation records, retaining source provenance and hashes separately; never tokenize or add templates to stored messages.

Proof: boundary equality/one-over/unknown/Unicode, role/payload privacy, exact history, consent OFF/revoke/stale/restart, atomic failure/duplicate retry, stop/error/archive/disconnect, HTTP CSRF/Origin/Hermes/execution refusal, synthetic engine, Node controller and Windows/Linux CI. Real-engine and installed-owner acceptance remain separate NOT TESTED gates. Rollback is source-only with additive DB retention and owner backup approval before any installed update.
