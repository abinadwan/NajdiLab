## Review decisions and limitations

Independent review identified and the implementation addressed: stale cross-tab model consent (selection revision), mapped network filesystem metadata access (locality check before stat), chunk trailer/header bytes escaping body limits (total wire reader), and the unjustified statement that no external hook existed (now explicitly uninspected). Tests cover the material failure modes. The live acceptance tool was retired because database-only redaction never proved sender wire privacy.

The feature intentionally offers fixed numeric IPv4 default endpoints only; custom ports/remote/IPv6-only/authenticated APIs remain unsupported. Model tests may load a model/use compute, but do not pull/unload models or collect application history. Selection/consent are shared by tabs in one server process and lost on restart. Local disconnect does not cancel compute already accepted by the runtime. Directory evidence is skipped when local filesystem provenance cannot be established; no recursive installation search exists. No schema migration, new application dependency or training permission was added. CI also builds a separately classified Core profile; it receives the same Hermes receiver safety correction and explicit classification/hash updates, while runtime integrations remain excluded from that profile. Its 11 builder tests and 18 subtests passed; publication remains unapproved.
