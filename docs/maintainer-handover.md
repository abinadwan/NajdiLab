This cleanup is source-only; rollback requires a reviewed source revert, no schema/data rollback. Earlier source can reopen removed interfaces or unsafe Hermes ingress, so review it before launch. Use [private backup/new-location restore](backup-and-restore.md) for any later installed update; never overwrite live evidence. No publication, history rewrite, installed update or external-service action is inferred from a source change.

Ownership/AI-material/contributor/employer authority, active license, holder/year/notices/assets, private history/data disposition and exact public manifest/destination remain open. [Release gates](public-release-decision.md).
